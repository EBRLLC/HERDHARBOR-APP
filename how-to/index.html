Getting Started

Set up the operation once, then work from Dashboard, Animals, or Quick Add.

Estimated 2–4 minBasicApp area: Dashboard
Open this in HerdHarbor →
Finish your operation profile. Enter the farm, rabbitry, homestead, or operation name and the adult account holder information requested during registration.
Add your first animals. Use Animals or Quick Add. Enter factual information you know; do not guess missing pedigree, health, or genetic information.
Use Dashboard for today’s work. Dashboard combines existing tasks and dated follow-ups so you can see what needs attention without maintaining another list.
Use the animal profile for animal-specific work. Open the animal first, then choose the relevant Health, Breeding, Genetics, Pedigree, Shows, or History action when available. Use Budget for production records.
Tip: HerdHarbor follows an “enter once, reuse everywhere” rule. When a fact already exists in a record, downstream tools should reuse it rather than asking you to create a duplicate.

03

How to Create a Pedigree

Build the ancestry around an existing animal and review it before saving or printing.

Estimated 3–5 minBasicApp area: Pedigrees
Open this in HerdHarbor →
Open the animal, then choose Pedigree. You can also open the Pedigrees area and select the subject animal.
Add the known parents and ancestors. Match existing HerdHarbor animals first. Create an ancestor-only record only when that ancestor is not already in your records.
Match existing ancestors whenever possible. Reuse an animal already in HerdHarbor instead of creating duplicate ancestry records.
Fill only verified ancestor details. Names, registration numbers, colors, breeds, and other fields should reflect the source you actually have.
Review the pedigree preview. Check sire/dam placement and each generation before saving.
Save, then print or export from the pedigree view. The saved pedigree remains tied to the subject animal and can be reused by genetics and breeding tools where supported.
Best practice: If an ancestor already exists as an active, archived, sold, or ancestor-only animal, match that record rather than typing the same animal again.

How to Enter a New Birth or Litter

Start from the breeding when one exists so sire and dam remain connected automatically.

Estimated 2–4 minBasicApp area: Births & Litters
Open this in HerdHarbor →
Open Births & Litters and choose + Record birth, or choose Record birth on the breeding. Select the breeding that produced the birth whenever one exists so sire and dam stay linked.
Enter the actual birth information. Record the birth date, born alive, stillborn, fostered young, losses, expected weaning date, and other fields that apply.
Save the birth record first. When it is linked to a breeding, HerdHarbor marks that breeding delivered, closes its expected-birth reminders, and can create the weaning reminder from the saved date.
Create individual offspring from the saved birth card. Choose Create offspring or Add offspring, then add the individual animals you want tracked. Parentage carries forward from the linked breeding.
Update the same birth record as the litter develops. Record later weaned or lost-before-weaning counts instead of creating a second birth record.

08

How to Use Genetics & Rabbit Pair Analysis

Open Genetics from the animal profile. Rabbits can use Pair Analysis; other supported species use their species-specific genetics tools. For rabbit Pair Analysis, read visible-color possibilities first, then locus detail, evidence, pedigree context, and data-quality notes.

Open a rabbit profile and choose Genetics, then Pair Analysis. HerdHarbor opens its specialized rabbit genetics tools; supported other species use the appropriate genetics tools. Select one active buck and one active doe and choose View Genetics Prediction.
Read Possible Offspring first. These are visible coat-color outcomes that remain compatible with the parents' recorded phenotype, genotype, carrier, pedigree, and offspring evidence. Color names such as Black Harlequin or Black Magpie describe coat phenotype/pattern, not the rabbit breed or show recognition.
Use the first results as the quick view. HerdHarbor keeps the first ten color outcomes visible and puts a long uncertainty tail under More genetically possible colors. Nothing is discarded; the extra rows are simply collapsed to keep Pair Analysis readable.
Know the difference between a percentage and a range. A single percentage means the relevant recorded Mendelian genotype is resolved. A range such as 0%–14.06% means unresolved alleles allow several valid parental genotypes. The low and high values are the minimum and maximum across those valid scenarios.
Do not add the displayed ranges together. Each outcome's minimum and maximum can come from a different hidden-genotype scenario, so uncertainty ranges are not one probability distribution and are not expected to total 100%.
Use the Uncertainty preserved label as a warning, not an error. HerdHarbor intentionally leaves unknown alleles unknown instead of guessing a carrier state just to produce cleaner-looking percentages.
Quick example: If both parents are recorded as V/v at the Vienna locus, the genotype calculation is 25% V/V, 50% V/v, and 25% v/v (Blue-Eyed White). V/v does not predict how much visible Vienna marking an individual kit will show.
Review Extended loci for the technical detail. Calculated means HerdHarbor has enough information for a Mendelian cross. Unresolved means a parental allele is missing. No Mendelian percentage is intentional for complex, polygenic, variable-expression, or informational traits where a simple percentage would be misleading.
Breed context keeps unrelated specialty loci out of the main view. When both parents are the same mapped breed, HerdHarbor highlights loci normally relevant to that breed plus any locus supported by recorded evidence. For example, two Holland Lops will not have Rex, Satin, Lionhead-mane, or other specialty loci presented as expected traits unless evidence for that locus exists. Hidden loci are not declared biologically impossible and remain available for crossbred cases or when direct recorded genetics/trait evidence supports them.
Review Evidence used before trusting a narrow result. The list shows why HerdHarbor believes an allele is present, such as phenotype, recorded offspring, pedigree, breeder-entered information, or a genetic test. Evidence status is provenance, not a claim that every inferred allele was DNA tested.
Use Pedigree relatedness context as descriptive ancestry information. Shared ancestors are reported from the recorded pedigree. An incomplete pedigree does not prove the pair is unrelated, and HerdHarbor does not invent an inbreeding coefficient from missing ancestry.
Use Recorded pair history and offspring context as historical records. Prior litter size, survival, weights, health, production, and show records describe what is actually stored for that pair or offspring. Missing records are not treated as zero performance or guaranteed health.
Read Data-quality review and Why these results? before saving the prediction. These sections explain missing pedigree/genotype information and why a result is exact, ranged, unresolved, or intentionally left without a percentage.
How to make the prediction more precise: Record accurate phenotype/color, verified genotype or carrier status, correct sire/dam links, informative offspring colors, and known ancestors. Add only evidence you actually know. As compatible hidden genotypes are eliminated, broad ranges should narrow automatically.
Genetics note: Pair Analysis is a breeding-planning model based on the records in HerdHarbor. It is not a DNA test, does not replace breed-standard or veterinary guidance, and does not turn missing evidence into certainty.

Marketplace

Browse publicly, then sign in only when you want to interact with a seller or manage Marketplace activity.

Estimated 2–4 minBasicWebsite area: Marketplace
Open Marketplace →
Browse without signing in. Anyone can view active listings. Use search plus Species, Breed, Sex, State / region, Pedigree, Listing type, price, and sort filters to narrow the results.
Sign in when you want to interact. A HerdHarbor account is required to save a listing, message a seller, block or report, create listings, or use Marketplace account tools.
Complete Seller Profile before publishing. You can create and save a draft first, but a listing cannot become Available until the seller profile is active. A suspended seller profile cannot publish.
Create the listing from Marketplace seller tools. If the animal already exists in HerdHarbor, use Select From My Herd when available. That connection is required for a public pedigree preview; manually entered listings keep pedigree preview hidden.
Choose the listing state deliberately. Available listings appear in normal Browse. Pending, Sold, Archived, and expired listings do not. Use the listing controls to mark pending, sold, available again, archived, or renewed.
Keep private records private. Messaging stays inside Marketplace. When a seller shares a HerdHarbor pedigree preview, it is read-only and excludes private herd notes, health data, contact details, photos, internal IDs, and sync metadata.
Buyer note: You do not need a Seller Profile to browse or message a seller. Seller Profile is required for publishing your own listing.

13

Trial, Membership & Referrals

Current account access, billing, fallback, and referral behavior.

Estimated 2–3 minBasicApp area: Settings / Subscription
Open this in HerdHarbor →
Eligible adult accounts receive one calendar month of Member trial access. Trial timing comes from the authenticated backend account record; browser storage cannot create or extend a trial.
No credit card is required to begin the trial. If you subscribe during an active trial, the remaining trusted trial period is preserved before Member billing begins.
Free Adult is an automatic fallback state, not a selectable account or signup plan. Eligible adult accounts move to Free Adult when the initial Member trial ends without a paid subscription or after paid Member access actually ends. If a paid Member subscription is canceled or a payment failure ultimately ends paid access, the account falls back automatically instead of deleting the herd. Existing animals and records remain stored. Free Adult allows up to five active animals for new growth while an existing over-limit herd can still be managed and reduced.
Junior remains a separate selectable signup path. Signup currently lets you select Junior or Member. Business is shown as Coming Soon and cannot be selected. Free Adult is never offered as a plan choice, and adult fallback does not convert the account into Junior.
Manage billing from the account/subscription controls. Checkout and Customer Portal actions use Stripe; provider or payment errors do not erase the current herd record.
Share only your public Referral ID. The Referral ID is separate from authentication/database identifiers, and qualifying referral credits follow the current referral policy shown in the subscription experience.
If Member access ends: HerdHarbor does not delete the animals or records. The backend resolves an eligible adult account to the Free Adult fallback. A temporary payment failure may remain in the provider retry/past-due lifecycle until Member access actually ends.

Cloud Sync & Offline Use

HerdHarbor keeps a protected cloud copy and an offline recovery copy so supported work can continue through normal connection changes.

Estimated 2–4 minIntermediateApp area: Settings
Open this in HerdHarbor →
Watch the sync indicator. The sidebar/top bar reports whether HerdHarbor is checking, syncing, or working from protected account storage.
You can continue supported work offline. The app keeps an offline copy on the device and synchronizes changes when connectivity returns.
Allow sync to finish before switching devices when possible. This reduces the chance of creating competing edits to the same record.
Do not treat the device copy as your only backup. Sign in to the correct HerdHarbor account and confirm cloud sync for records you need across devices.

Budget & Expenses

Settings, Account & Data

Settings is the control center for your account, operation profile, membership, data tools, sync, and app preferences.

Open Settings from the Account area. Use Edit profile for operation details and the Appearance controls for presentation changes.
Review Membership before changing billing. Junior and Member are selectable account paths where available. Free Adult may appear as the current automatic fallback state, but it is never a plan you select.

Use Excel spreadsheet import for bulk record entry. Choose Download Excel template, fill the supported sheets, then Upload Excel file and review valid rows, duplicates, and errors before confirming.
Use the dedicated Account deletion and Privacy controls when needed. Clear local data only removes this device's working copy; it is not account deletion and is not a substitute for signing out or switching accounts.

Local/cloud comparison

HerdHarbor protects unsynced local work and does not silently overwrite it with an older cloud snapshot.

Free Adult is not a selectable plan. It is the automatic fallback for an eligible adult account after Member access ends.

Common Questions

Fast answers to the issues that usually cause confusion.

Do I need a Seller Profile to use Marketplace?

No. Anyone can browse. Signed-in members can save listings and message sellers without a Seller Profile. Seller Profile is required only when you want to publish your own listing.

Why don’t I see every tab on every animal?

Animal-profile tabs are contextual. HerdHarbor only shows actions relevant to the animal/species and the data or tools available for that record.

Should I enter the same weight in Health and Analytics?

No. Enter the measurement once in the canonical Health/measurement workflow. Analytics should read that record.

Should I create a new litter without selecting the breeding?

If a breeding record exists, start from or select it so sire and dam information carries forward correctly. Use a standalone birth/litter only when there truly is no applicable breeding record.

Will I lose records if Member access ends?

No. HerdHarbor does not delete herd records because Member access ends. Eligible adult accounts automatically fall back to Free Adult. Free Adult is not a selectable signup plan; Junior remains a separate signup path.

Is the Symptom Guide veterinary advice?

No. It is educational information for recognizing urgency and organizing observations. Veterinary diagnosis and treatment decisions belong with a veterinarian.
