# HerdHarbor Alpha v1.6.6

## Mobile Analytics Hotfix

Alpha v1.6.6 is a focused production hotfix for the Growth Analytics controls on narrow mobile screens.

### Fixed

- Prevented the **Compare animals and choose stable colors** control from overflowing or clipping animal names on mobile.
- Constrained the Growth controls to the viewport width.
- Added mobile-safe wrapping and width constraints for animal color controls.
- Added Safari-compatible layout handling for the existing nested-label parsing behavior so checkbox/color rows remain usable on iPhone-sized screens.

### Scope

This release intentionally contains only the urgent mobile Analytics layout correction and release identity changes. The broader completion-debt work previously prepared as v1.6.6 has been moved forward to **Alpha v1.6.7** for separate review.
