# v1.8.4 Authentication Regression Acceptance

Authentication architecture is frozen for v1.8.4. This phase adds regression protection only; it does not redesign sign-in or signup policy.

Protected paths:
- existing-user sign-in
- logout then sign-in
- hard refresh and session restoration
- expired-session handling and supported refresh
- auth callback deferral outside the Supabase auth notification lock
- PWA/mobile startup without stale auth overlay or deadlock
- bounded critical auth/first-hydration requests
- one canonical browser Supabase client
- protected account behavior
- registration overlay reuse of the canonical HerdHarborCloud client

Any future auth code change in this release requires a verified defect and focused regression coverage.
