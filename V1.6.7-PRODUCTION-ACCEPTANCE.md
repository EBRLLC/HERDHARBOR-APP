# Alpha v1.6.7 production acceptance

Use this checklist only after the v1.6.7 code review is approved. Repository tests do not substitute for external-service checks.

## 1. Baseline release gate

- [ ] Live Alpha v1.6.6 mobile Analytics hotfix is present in the release base.
- [ ] `npm ci`
- [ ] `npm run test:completion`
- [ ] Full `node --test tests/*.test.cjs` passes in UTC.
- [ ] Full suite passes in `America/New_York`.
- [ ] Monitoring bundle builds from the pinned lockfile.
- [ ] Android/TWA review AAB builds and verifies.
- [ ] Source-mutation guard confirms tests/builds did not change tracked source.

## 2. v1.5.1 membership acceptance

Use dedicated acceptance accounts; never use customer credentials.

- [ ] Owner signs in and can open the protected Admin member directory.
- [ ] Active Admin can open the protected directory.
- [ ] Ordinary User is denied the directory and admin mutation RPCs.
- [ ] User cannot self-promote or self-assign a membership override.
- [ ] Owner protection prevents demotion/duplicate Owner creation.
- [ ] Freshly registered test account resolves to User + Member + Default + Active.
- [ ] Manual membership override wins over automatic membership.
- [ ] Expiring override falls back correctly after expiration.
- [ ] Return to Automatic Membership removes the override without touching farm data.
- [ ] Admin audit history contains actor, target, action, previous/new values, reason, and timestamp for controlled test changes.
- [ ] Junior at 0, 1, 4, and 5 active animals behaves normally.
- [ ] Sixth active animal is rejected.
- [ ] Sold, Deceased, Archived, and Ancestor Only records do not consume Junior slots.
- [ ] Releasing a slot permits a new active animal.
- [ ] Junior import, transfer, litter-offspring, backup restore, Cloud Sync, offline restart, and two-device behavior preserve all records and enforce the centralized transition rule.

Read-only checks can be run with:

```bash
node scripts/membership-production-acceptance.mjs
```

## 3. Sentry delivery acceptance

- [ ] Production DSN is supplied only through the approved environment/secret path.
- [ ] Run `node scripts/sentry-production-acceptance.mjs` with `HERDHARBOR_SENTRY_DSN` configured.
- [ ] Confirm the reported event ID appears in the expected Sentry project.
- [ ] Confirm release `HerdHarbor@1.6.7`, build `completion-debt-1`, production environment, and synthetic-only classification.
- [ ] Confirm the event contains no farm state, animal/customer data, notes, credentials, auth/session tokens, request body, cloud payload, or financial/health content.

## 4. Market backend deployment

Do not enable the hardened Market behavior before this deployment succeeds.

- [ ] Confirm `supabase/v1.6.5-market-analytics-foundation.sql` is already applied.
- [ ] Apply `supabase/v1.6.7-market-privacy-hardening.sql`.
- [ ] Confirm `market_private` remains inaccessible to `public`, `anon`, and `authenticated`.
- [ ] Confirm only service-role execution is available for Market RPCs.
- [ ] Deploy `supabase/functions/market-contribution/index.ts` as `market-contribution` if the function source changed or requires redeployment.
- [ ] Confirm the Edge Function requires a valid authenticated Bearer token and resolves the caller through Supabase Auth.

The manual production workflow may perform these steps only when explicitly selected and the protected production environment is approved.

## 5. Market consent and contribution acceptance

Use synthetic test sales only.

- [ ] Market consent defaults OFF.
- [ ] Enabling Market consent does not enable/alter Cloud Sync, billing, or membership.
- [ ] Historical contribution remains OFF unless separately selected.
- [ ] Draft / Reserved / Pending sales contribute nothing.
- [ ] First transition to Completed creates one item-level observation per sold animal.
- [ ] Sale item correction updates the same observation rather than duplicating it.
- [ ] Removing an item or cancelling a completed sale withdraws the observation.
- [ ] Offline completion queues the contribution.
- [ ] Restoring connectivity retries automatically with bounded backoff.
- [ ] Successful Cloud Sync triggers another immediate retry opportunity.
- [ ] A queued contribution that initially races ahead of canonical cloud state eventually succeeds without another unrelated user action.
- [ ] Opting out removes queued local contributions and local receipts.
- [ ] Opting out removes prior backend contributions for that user.
- [ ] Account deletion removes Market consent/processing/facts for that user.

## 6. Market fact/privacy acceptance

For a synthetic animal listed at $125 and sold at $100:

- [ ] canonical animal `askingPrice` remains $125 after sale;
- [ ] sale item `listedPriceAtSale` preserves the factual listing snapshot;
- [ ] sale item `salePrice` / actual sale remains $100;
- [ ] no historical asking value is fabricated where no snapshot exists.

Inspect the private fact table using authorized administrative tooling only:

- [ ] species/breed/sex/age/color/pedigree/registration/region/currency/sale facts only;
- [ ] no customer name/email/phone;
- [ ] no breeder/farm/rabbitry name;
- [ ] no animal name or raw animal/account/customer identifier;
- [ ] no exact street address or exact coordinates;
- [ ] no notes, medical text, photos, documents, payment reference, or cloud storage path.

## 7. Market aggregation privacy acceptance

- [ ] 1–4 matching observations => `available:false`; exact count is not returned.
- [ ] 5–9 matching observations => averages/medians may be returned; exact minimum/maximum keys are absent.
- [ ] 10+ matching observations => minimum/maximum may be returned.
- [ ] Species, breed, sex, age bucket, color/variety, pedigree, registration, region, month, year, currency, and date filters are applied before thresholds.
- [ ] USD and CAD or any two currencies cannot be mathematically combined.
- [ ] Raw market rows are never returned to ordinary clients.

## 8. PWA/mobile regression acceptance

- [ ] Installed v1.6.6 client detects the v1.6.7 update.
- [ ] Update Now works without requiring Cloud Sync.
- [ ] Unsynced local farm data remains safe.
- [ ] Service worker activates `herdharbor-shell-v1.6.7-alpha-completion-debt-1`.
- [ ] iPhone/narrow-screen Growth Analytics **Compare animals and choose stable colors** remains contained, readable, scrollable, and free of horizontal overflow.
- [ ] Genetics, Shows, Sales, Finance, Health, Production, memberships, and offline launch remain functional.

## 9. Release decision

Do not call Alpha v1.6.7 live until the code is merged, required external deployments are complete, and post-deployment smoke checks pass.
