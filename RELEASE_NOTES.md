# HerdHarbor Alpha v1.8.2

The current HerdHarbor release is **Alpha v1.8.2**.

This release formally closes out the animal-first profile architecture, continuous breeding/litter workflow, automatic offspring creation, Litter Workspace, sales/member transfer flow, Breeding Next-Action guidance, Breeding Performance Analytics, Rabbit Genetics V2 Phases 1–3, and the safely reintroduced mobile web install entry.

The approved v1.8.1 subscription/account policy is carried forward unchanged, including the September launch trial and October 1, 2026 hard subscription launch.

See [`RELEASE_NOTES-v1.8.2.md`](RELEASE_NOTES-v1.8.2.md) for the complete current release contract.

Historical release notes remain available through Git history and prior release documents rather than being treated as current repository guidance.
