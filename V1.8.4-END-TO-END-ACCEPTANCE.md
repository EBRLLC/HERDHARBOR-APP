# v1.8.4 End-to-End Regression Acceptance

Phase 8 combines the already-proven stability owners into one release-candidate regression surface.

Required journeys:
- sign in / session restore / sign out and sign in again
- create and edit canonical animal records
- breeding -> pregnancy -> birth -> offspring -> weight -> weaning -> retained
- litter evaluation -> sale -> completed sale -> direct member transfer
- replayed transfer does not duplicate animal or pedigree data
- same-record cross-device edits stop as conflicts instead of silently overwriting
- non-overlapping cross-device edits reconcile
- offline/reconnect and retry preserve canonical state
- PWA update lifecycle preserves user data and session boundaries
- subscription checkout/failure/cancellation transitions remain non-destructive
- cloud failure diagnostics preserve provenance and privacy
- normalized-sync rollout remains gated and reversible

The aggregate release-regression command is test-only. It must not deploy, apply production schema, mutate Stripe, enable rollout cohorts, or merge PRs.
