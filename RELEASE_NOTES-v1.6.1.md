# HerdHarbor Alpha v1.6.1

HerdHarbor v1.6.1 consolidates the analytics, rabbit-genetics, standards, and multi-species work into one current application release based on `main`.

Business and farm-management workflows remain available in Alpha v1.6.1, including cattle identification, customers, sales, payments, production, health, budgeting, and exports.

## What is included

- Farm analytics calculated from existing HerdHarbor records, with date and species filters.
- Complete domestic rabbit genetics tools for profiles, breeding predictions, pedigrees, recorded evidence, and uncertainty-aware outcomes.
- Shows, production, and health analytics surfaced alongside the rest of the farm workflow.
- Optional breed-standard references and multi-species genetics guidance. These enhancements do not block the core records experience when reference data is unavailable.
- A consolidated 1.6.1 application shell, cache, manifests, monitoring release, and mobile package metadata.
- In-app links to support, privacy, terms, and account-deletion resources.

## Upgrade and data safety

Existing accounts, locally stored farm records, cloud records, backups, and migration history remain compatible. Versioned storage and database identifiers that protect that compatibility are intentionally unchanged.

Superseded 1.4.x, 1.5.0, and unversioned executable copies were removed from the active repository. Historical release notes and database migrations remain available for audit and recovery purposes.
