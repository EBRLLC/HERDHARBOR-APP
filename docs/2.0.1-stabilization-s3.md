# 2.0.1 S3 — printed document and lineage performance stability

- Replaced per-path repeated-ancestor traversal with iterative three-state DFS. Each reachable dog and parent edge is visited once, while path-local cycles remain rejected. The algorithm handles legitimate shared ancestors without exponential work. Synthetic stress tests cover 100 shared ancestor records and real cycles.
- Applied the selected registry consistently to the main pedigree chart **and** the supplemental full-text appendix; a registry unavailable to an ancestor falls back to that ancestor's preferred registration rather than fabricating an identifier.
- Placed the full-text appendix outside the constrained pedigree sheet. This avoids trapping additional pages in the chart's flex/page-height box.
- Added fail-closed checks when the shared renderer's sale/certification sections or HTML shell change; this is safer than silently producing an unlabelled or improperly certified Dog pedigree.
- Kept all Rabbit standard renderer functions untouched; no legacy Rabbit CSS or canonical animal records are changed.

Known gap: HTML tests do not prove a desktop/iOS print engine's physical page breaks. The owner acceptance checklist still requires actual landscape Letter/A4 PDF capture and long-name comparison before production.
