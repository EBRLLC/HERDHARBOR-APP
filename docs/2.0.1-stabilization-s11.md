# HerdHarbor 2.0.1 — S11 PWA and native release identity cutover

This PR is **staged and unmerged**, stacked on S10 #494. It changes repository release-candidate assets only. Stable production `main` and existing installed 2.0.0 apps remain untouched until an owner-approved release.

## Coherent version owners
- Whole-app runtime and build ID: 2.0.1 / `v2.0.1-release-1`.
- Web manifest, npm package and lockfile, release metadata, cloud-sync app-release telemetry and monitoring generator use 2.0.1.
- TWA and embedded Android manifest are 2.0.1; Android `versionName` is 2.0.1 and `versionCode` increases from 19 to 20.
- Service worker uses a new 2.0.1 shell cache. Source HTML and preload query identities agree; the content-hash release builder still rewrites deployable JS/CSS with `?rev=` fingerprinting and derives the final cache identity from asset hashes.

## Offline canine guarantees
Five essential canine files (breeds, identity model, lineage, unofficial pedigree print, identity CSS) are included in the install-time required shell. The worker treats any failure of those assets as fatal to installation, preserving the previous functional shell instead of activating a partially installed 2.0.1 app.
Dynamic photo/paper AI stays optional and network-dependent, not part of offline core. All manual animal workflows remain available.

## Tests and release boundaries
A new S11 contract test verifies consistent version identifiers, native code bump, current source/precache URLs, and an execution-level service-worker installation failure. Current-release assertions are updated for 2.0.1; historical 2.0.0 production contract documents and deployments are retained unchanged.

**Pending before public rollout:** owner-reviewed final stack, real iPhone/Android browser/update and offline testing, real PDF appearance on Letter/A4, live account A/B cross-device synchronization, and approval of the AI entitlement tier matrix. No merge, Pages/TWA deployment, schema migration, user state modification, or public AI switch is part of this PR.
