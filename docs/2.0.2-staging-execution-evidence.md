## Independent encrypted archive reader (new code)

The branch now includes `scripts/s19-independent-backup-verify.cjs`, a separate offline verifier that does not import the migration writer or its `restoreBackup` function. It checks the AES-256-GCM authentication tag, scrypt-derived key, expected account UUID, independently computed plaintext SHA-256, and archive envelope, and refuses to overwrite an existing restoration output. It exposes an explicit `--output` option for a secured offline destination; it never logs plaintext.

`tests/v2.0.2-independent-recovery.test.cjs` uses a different Node process and destination directory to exercise a full mixed-species encrypted archive, includes a tombstone, checks mode 0600, and rejects wrong passphrase, wrong account, wrong checksum, reused output path, and corrupted ciphertext.

**Scope distinction:** A successful CI test of this utility proves independent archive decryption and local-file restoration. It does **not** prove PostgreSQL restoration into an independently provisioned database, nor operational recovery of a real customer farm. Those release gates remain **NO-GO** until separately verified.
