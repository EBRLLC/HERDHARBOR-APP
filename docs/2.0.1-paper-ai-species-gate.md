# 2.0.1 Paper Pedigree Reader — species release decision

The existing AI reader is a **rabbit pedigree** image extraction and human-review system. Its extraction schema and prompt explicitly reference rabbit pedigree layouts, and its canonical import core previously defaulted missing species to Rabbit.

## Implemented
- Request contract explicitly sends `species: Rabbit` for existing paper reader calls.
- The server rejects non-rabbit requests before model invocation/quota reservation and rejects non-rabbit extracted nodes after structured provider output.
- Reviewed/imported Dog/Cattle/Horse drafts fail closed at the UI, plan creation, and `applyImportPlan` canonical mutation boundary.
- Rabbit extraction, uncertainty review and import still reuse the existing canonical image quota, reviewed import and state commit path.
- A dog with registered name, AKC number and titles must use the manual canine editor and breeder-maintained print until a canine-specific model/prompt/corpus is validated.
- This does **not** perform breed recognition or title extraction on canine image uploads; it is intentionally not presented as supported.

## Quality corpus decision
No authenticated, permission-cleared canine pedigree photo corpus was supplied to or verified in this PR. There is no defensible measured accuracy for canine title/registration extraction, especially under damaged scans or ambiguous parentage. **Canine AI paper scanning remains disabled** and must not be released or advertised on the strength of rabbit tests.

A later gated canine release requires an owner-approved reference corpus representing 3-/4-generation pedigrees, long AKC registered names, CH/GCH prefix and CGC/CD suffixes, registration provenance, rotated low-contrast photos, repeated ancestors, missing entries and intentionally contradictory parentage. The exact title display order must be compared field-by-field with ground truth; no inferred title is considered verified.

This PR does not change Edge Function deployment, pricing, subscription permissions, AI enable flags or production data. Full UI/browser/cross-account acceptance remains R1.
