# v1.8.4 PWA / Service-Worker Update Acceptance

Phase 5 protects release-to-release web and installed-PWA updates without changing canonical farm data or cloud authority.

Acceptance:
- v1.8.3 shell can discover a newer candidate through service-worker update checks
- waiting workers activate only from the explicit Update Now path
- controller change reloads into the activated shell
- old HerdHarbor shell cache generations are removed while unrelated caches are untouched
- release-critical assets remain network-first with offline fallback
- navigation falls back to the cached application shell after one successful load
- protected/cross-origin auth and API traffic is never answered from the static shell cache
- hard refresh, reconnect, installed-PWA launch, mobile startup and desktop startup retain the same canonical application state

Broad cache clearing is not an acceptable substitute for the existing lifecycle behavior.
